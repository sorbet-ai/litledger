## Notes
- Every dictionary-word candidate is already taken on PyPI and npm; only `litledger` and `citedel` are free everywhere checked. Taken-ness is not fatal: the Docker image and CLI can use a suffix, but a PyPI distribution name must be distinct, so a free PyPI name is a real advantage.
- Docker Hub: no candidate has an official library image (all 404). Pre-existing `<name>/<name>` namespace squatting: only `gloss/gloss` exists.
- Closest-space conflicts: `carrel` PyPI pkg (agent file library, Sep 2026), `colophon` PyPI pkg (provenance chains), `marginalia` PyPI pkg (Obsidian/academic markdown), `scholia-oss` and Wikimedia Scholia (scholarly), `weft` (agent infra), `cairn` (several AI-agent tools incl. cairn-mcp), `exlibris` (library systems vendor).
- `litledger` is descriptive (literature + ledger, matches provenance-tracked evidence) but unbrandable-sounding; `citedel` is a cite + citadel pun, French "cite de l-" collisions are cosmetic. Both lack search-engine presence, which is an advantage.
- Limits: GitHub search unauthenticated and rate-limited (retried); WebSearch returned no name-specific product data, so the product-conflict column leans on background knowledge. Trademark registries were not queried. GitHub star counts are as of the check date.
- Fallbacks if a favored word is wanted: `<word>-lit`, `<word>-mcp` (all `-mcp` PyPI names free except cairn, folio).
